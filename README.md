# Rice Leaf Disease Detection 🌾

## Project Overview
Rice Leaf Disease Detection is a machine learning project developed using Python and Jupyter Notebook. The project focuses on identifying diseases in rice leaves through image-based analysis.

The objective is to explore how machine learning and image processing can help detect rice leaf diseases and support agricultural decision-making.

## Technologies Used
- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Machine Learning / Deep Learning

## Project Structure
```text
Rice-Leaf-Disease-Detection/
│
├── rice leaf project.ipynb
└── README.md
```

## Implementation
The project is developed in a Jupyter Notebook, covering the workflow for rice leaf disease detection, including image analysis and model development.

## How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com/Anjaly-Jins/Rice-Leaf-Disease-Detection.git
   ```
2. Install the required dependencies.
3. Open Jupyter Notebook.
4. Run `rice leaf project.ipynb`.

## Project Purpose
This project demonstrates the application of machine learning and image-based analysis in agriculture, with a focus on rice leaf disease identification.
